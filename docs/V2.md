# English Communication AI V2

## Scope
- 197 original lessons and 985 original bilingual examples are unchanged.
- 432 bilingual vocabulary entries: words, phrases and complete conversational expressions. Each lesson links to 5–6 entries with an existing English/Vietnamese example. Expressions are explicitly labeled.
- Personal wordbook, search, lesson/status filters, 24-entry pagination, listening, self-rated flashcards and review dates (1/3/7/14/30 days).
- 591 exercises: one multiple-choice meaning, one fill-in-the-blank and one sentence ordering exercise per lesson. Content and correct answers come from the existing curriculum.
- Immediate rule-based grading, model answers, missing/extra words or word-order feedback, formula explanations, retries and mistake reviews.
- First-answer scores are immutable. Latest-answer accuracy and attempt counts are separate, computed over answered questions; they are not a CEFR or proficiency assessment.

## Storage and compatibility
The existing `english-communication-ai:v1` storage key remains authoritative on the same website origin. V2 adds `words` and `answers` to the original `completed`, `notes`, `reviews` and `startedAt`. On the first V2 write to legacy data, the old payload is retained at `english-communication-ai:v1:before-v2`. No V1 payload is rewritten just by loading the page.

V2 exports use `version: 2`. Importing a validated V1 backup replaces only V1 lesson progress, notes and review dates; it retains the current V2 wordbook and exercise records. Importing V2 replaces all current learning data after confirmation. Invalid imports are rejected before mutation. Unreadable existing local data is protected from writes until the user explicitly imports or resets; its raw payload can be downloaded from Settings.

V1 code does not understand a V2 backup. Users should keep V2 backups for future restores. No server account, API key, external AI service or paid dependency is introduced.

## Grading rules
English answers accept case, Unicode apostrophe and ordinary punctuation variations, and supported unambiguous contractions. Decimal numbers and percentages remain meaningful. Multiple-choice answers are checked against the exact displayed option (including Vietnamese diacritics). Sentence ordering follows the model sentence; this does not assess all possible free-form translations. Self-written lesson notes remain ungraded.

## Validation
`python3 tests/verify_data.py`, `npm run test:logic`, and `npm test` cover original data, V2 linked content, grading/normalization, first/latest score separation, wordbook/flashcards, wrong-answer reviews, legacy migration/import, backup roundtrips, reset/restore, offline use and responsive layouts. The Actions workflow repeats browser tests against the actual Pages URL after deployment and retains screenshots in its artifact.

## Branch and release
Develop on `develop/v2-vocabulary-exercises`; integrate with main through a PR after CI passes. GitHub Actions deploys the static website. Current deployment status is authoritative in Actions.
